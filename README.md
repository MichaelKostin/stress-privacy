# Honest Stress Tracker legal pages

Static legal and support pages for **Honest Stress Tracker**.

## Pages

- `/privacy-policy.html`
- `/terms-of-use.html`
- `/support.html`
- `/index.html`

English only for the early launch. Localized folders can be added later using the same pattern as Puzzle Garden.

The site has no build step. Serve the directory with any static web server.

## Hosting

GitHub Pages with custom domain `stress.kostin.app` (see `CNAME`).
